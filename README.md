## 📎КАКИЕ ФАЙЛЫ ЗА ЧТО ОТВЕЧАЮТ

- `main.py` Файл с мозгом для ИИ
- `TG.py` Телеграмм чат с Администратором

## Список технологий и библиотек:

**Язык:** `Python 3.13` использовался для полного создания логики и бэкэнда, для **База данных:** `SqlAlchemy`, `TeleBot` для **работы в телеграмме**, `OpenAI` для **Мозг ИИ** 

## 🤖 Установка и запуск:



Скачать PyCharm, затем скачать python версии 3.13, закинуть все файлы в 1 проект, открыть папку в PyCharm, получить в Qroq API ключ API и вставить его в 3 строчку файла `main.py`"api_key=".

Используйте pip install -r requirements.txt для установки всего самого важного чтобы код работал
## Схема базы данных



| Поле | Тип                 | Описание                                              |
| ---- | ------------------- | ----------------------------------------------------- |
| id   | INTEGER PRIMARY KEY | id сообщения(для строения хронологии сообщений)       |
| user_id |INTEGER| Id пользователя                               |
| role | TEXT| кто пишет(система, пользователь или ИИ)|
| content | TEXT| Текст|
| Role | TEXT| для понимания ИИ'шкой кто пишет(пользователь или бот) |
